# 🎙️ North Voice — Autonomous AI News Agent

> **উত্তরবঙ্গের প্রতিটি জনপদের বলিষ্ঠ কণ্ঠস্বর**  
> Facebook Page: [facebook.com/northvoicebd](https://www.facebook.com/northvoicebd)

North Voice is a 100% automated, autonomous AI journalism agent that monitors, curates, designs, and publishes North Bengal local news to Facebook with pixel-perfect branded photocards.

---

## ✨ Features

- **Autonomous News Hunting:** Automatically scans 8+ verified Bangladeshi news RSS feeds (Prothom Alo, Daily Star, Dhaka Post, JagoNews, etc.) and Google News RSS for North Bengal districts (বগুড়া, রংপুর, দিনাজপুর, রাজশাহী, পাবনা, সিরাজগঞ্জ, নওগাঁ, কুড়িগ্রাম, পঞ্চগড়, ঠাকুরগাঁও, ইত্যাদি).
- **Gemini AI Chief Editor:** Evaluates regional importance, generates engaging 2-3 line Bengali headlines with smart highlights, writes Facebook captions with hashtags, and selects the ideal card template.
- **Dynamic Photocard Engine:** Renders crisp, modern, mobile-optimized (1080x1350) photocards using Playwright Headless Chromium and Google Fonts (`Hind Siliguri`).
  - `breaking.html`: Urgent alerts, accidents, and major regional updates.
  - `quote.html`: Editorial statements and high-impact quotes.
  - `general.html`: Development, agriculture, lifestyle, and local features.
- **Zero-Storage Deduplication:** Connects to **Supabase** via lightweight SHA-256 hash checks to prevent duplicate posts while storing zero images on servers.
- **GitHub Actions Automation:** Runs 24/7 on a 30-minute cron schedule completely free with full artifact archiving.
- **Dry-Run Safe Mode:** Runs safely in preview mode if Facebook credentials are not provided.

## 🚀 Setup & Credentials

In your GitHub repository (**Settings > Secrets and variables > Actions > New repository secret**), add:

| Secret Name | Description | Required |
| :--- | :--- | :--- |
| `GEMINI_API_KEY` | Google AI Studio Gemini API Key | Yes |
| `SUPABASE_URL` | Supabase Project URL (`https://xyz.supabase.co`) | Yes |
| `SUPABASE_KEY` | Supabase `anon` or `service_role` Key | Yes |
| `FB_PAGE_ID` | Facebook Page ID (e.g. `1234567890`) | For live posting |
| `FB_PAGE_ACCESS_TOKEN` | Long-lived Page Access Token | For live posting |

## 🗄️ Supabase Table Schema

In your Supabase **SQL Editor**, run:

```sql
create table posts (
  id bigint generated by default as identity primary key,
  url_hash text unique not null,
  news_url text not null,
  headline text,
  fb_post_id text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

create index idx_posts_url_hash on posts (url_hash);
```

## 💻 Local Testing

```bash
# 1. Clone repository
git clone https://github.com/beyond88/north-voice.git
cd north-voice

# 2. Setup virtual environment
python3 -m venv .venv
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt
playwright install chromium

# 4. Copy environment file
cp .env.example .env

# 5. Run the agent
python agent.py
```

Generated photocards will be saved to the `output/` folder.
